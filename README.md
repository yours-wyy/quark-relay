# Quark Relay · 夸克网盘代下载站

一个基于夸克网盘 SVIP 的网盘代下载 / 中转站点：用户提交夸克分享链接，凭「天卡」在 24 小时内高速下载。

## 项目文档

- [方案说明.md](方案说明.md) — 整体架构、核心链路、分发模式、天卡系统、成本与拍板清单
- [白话流程拆解.md](白话流程拆解.md) — 用"高速取货店"比喻拆解整套流程，回答关机、鉴权、下载机制、空间分配、验证容器
- [竞品拆解与复用.md](竞品拆解与复用.md) — AList / YunGet / 独角数卡的实测接口与复用清单

## 目录规划

```
docs/       文档
server/     后端 API（卡密、夸克适配层、下载网关、队列）
web/        前端
worker/     转存 / 直链刷新 / 清理 任务
scripts/    验证脚本（Cookie、直链、测速）
```

## 技术栈

Next.js / NestJS / PostgreSQL / Redis / BullMQ，Worker 建议部署于住宅 IP。
